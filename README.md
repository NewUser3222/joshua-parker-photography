## 🌟 Project Overview

Joshua Parker Photography is a responsive photography portfolio website built with **HTML5 and CSS3**. The project showcases photography through a clean layout featuring highlighted images, a photo gallery, and an About section.

The website was developed to demonstrate foundational front-end web development skills, including semantic HTML, modern CSS layouts, image presentation, and responsive design.

## ✨ Features

- 📷 **Featured Photography** — Three highlighted photography cards with hover overlays.
- 🖼️ **Photo Gallery** — Six additional photographs displayed in a structured CSS Grid layout.
- 👤 **About Section** — Photographer introduction with a profile image.
- 🧭 **Section Navigation** — Navigation links for Home, Portfolio, About, and Contact.
- 🎨 **Interactive Hover Effects** — Image overlays and CSS transitions.
- 📱 **Responsive Design** — Layout adjustments for smaller screens.
- 🧩 **Organized Styling** — Separate CSS stylesheet for layout and presentation.

## 🏞️ Website Sections

| Section | Description |

| 🏠 Home | Website introduction and featured photography |

| 👤 About | Photographer introduction and profile image |
| 📬 Contact | Navigation section and social link placeholders |

## 🛠️ Technologies & Concepts

- **HTML5** — Semantic page structure and content organization.
- **CSS3** — Styling, spacing, colors, and visual presentation.
- **Flexbox** — Flexible layouts for navigation and content sections.
- **CSS Grid** — Structured photography gallery.
- **CSS Transitions** — Smooth hover effects and image overlays.
- **Media Queries** — Responsive layouts for smaller screens.
